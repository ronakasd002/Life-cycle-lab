LifeCycle Lab

Plan it. Estimate it. Test it.

Every software project has a life cycle: it is modelled, specified, estimated and tested. LifeCycle Lab lets you run those four stages yourself, one after another, and then gives you a report of the whole journey.

LifeCycle
Lab
Why I built this. Our lab list had twelve separate experiments. I wanted to see what happens when four of them work together as one tool, in the same order a real project uses them. That journey is the life cycle the name talks about, and the tracker below follows it. The Java version runs in the terminal; this page is the same idea, made for the browser.
